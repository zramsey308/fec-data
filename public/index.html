Clawbot FEC Data

Processed FEC bulk data filtered to monitored congressional districts.

Data Files

  • district_summary.csv — per-district totals (raised, spent, net)
  • candidates.csv — candidate details
  • committees.csv — committee details
  • individual_contributions.csv — itemised individual donations
  • pac_contributions.csv — PAC / committee-to-committee donations
  • expenditures.csv — operating expenditures
